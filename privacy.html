Aeris privacy policy

Last updated: October 1, 2026

Aeris is a personal voice assistant used only by its owner, on the owner's own computer. It is not offered to the public.

What Google data Aeris uses

With the owner's permission, Aeris uses the Google Calendar API to read, create, update and delete events on the owner's own calendar, only when the owner asks it to by voice.

How the data is handled

  • The Google sign-in token is stored only on the owner's own PC.
  • To answer a question about the calendar, the relevant event details are sent to the AI model that powers Aeris (Anthropic's Claude) for that request.
  • Calendar data is not sold, shared with advertisers, or used for any purpose other than answering the owner's own requests.
  • Aeris's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the PC also removes Aeris's access.
